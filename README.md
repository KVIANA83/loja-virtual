# 🛍️ Loja Virtual Moda Estação – Moda Feminina

É uma loja virtual voltada para o público feminino, criada com o objetivo de oferecer roupas, calçados e acessórios alinhados às tendências da estação. O projeto busca unir estilo, praticidade e uma experiência de navegação simples e agradável, valorizando a identidade feminina e a facilidade de compra no ambiente digital.

# 🌐 Projeto Website Profissional (Portfólio)

## 📌 Sobre o Projeto

Este projeto iniciou-se como um **exercício prático de desenvolvimento web**, com o objetivo de aplicar conhecimentos em **HTML, CSS, JavaScript e Bootstrap**. Com o avanço do desenvolvimento, o projeto passou a ter um propósito maior: **evoluir para um website com padrão profissional**, servindo como base para estudos contínuos e melhorias futuras.

Atualmente, o projeto encontra-se em constante evolução, com ajustes estruturais, melhorias visuais, organização de código e implementação de boas práticas de desenvolvimento front-end.

## 🎯 Objetivo

O principal objetivo deste projeto é:

* Transformar um exercício acadêmico em um **website profissional**
* Aplicar conceitos de **responsividade, organização de pastas e reutilização de componentes**
* Servir como **portfólio pessoal**, demonstrando evolução técnica e prática em desenvolvimento web
* Criar uma base sólida para futuras implementações e novas funcionalidades

## 🛠️ Tecnologias Utilizadas

* **HTML5** – Estruturação das páginas
* **CSS3** – Estilização e layout
* **JavaScript** – Interatividade e dinamismo
* **Bootstrap** – Componentes visuais e responsividade

## 📂 Estrutura do Projeto

```
📁 css        → Arquivos de estilização
📁 images     → Imagens utilizadas no site
📁 js         → Scripts JavaScript
📁 links      → Arquivos e páginas auxiliares
📄 index.html → Página principal do projeto
```
